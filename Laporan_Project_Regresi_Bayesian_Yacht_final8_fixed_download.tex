\textbf{ABSTRAK}

Prediksi hambatan residu (\emph{residuary resistance}) kapal layar pada
tahap desain awal penting untuk menaksir kebutuhan daya propulsi.
Penelitian ini menjawab pertanyaan: \emph{seberapa stabil dan informatif
hasil Regresi Bayesian pada data Yacht Hydrodynamics ketika difokuskan
pada reproducibility dan kualitas data?} Data terdiri atas 308 uji
\emph{towing tank} dari 22 bentuk lambung × 14 Froude number. Analisis
mengikuti \emph{Bayesian workflow}: audit data, prior predictive check,
validasi komputasi (analitik, Gibbs, dan HMC), tujuh model bertahap
(M0--M6), diagnostik MCMC, \emph{posterior predictive check}, PSIS-LOO
dengan koreksi Jacobian, analisis sensitivitas, serta audit
reproducibility (seed, urutan data, dan skema validasi). Komputasi
\textbf{stabil secara substantif}: posterior MCMC cocok dengan solusi
analitik, dan probabilitas eksedans prediktif hanya bervariasi
0.757--0.765 antar lima seed. Uji formal \textbar z\textbar{}
\textless{} 3 MCSE menandai SD efek hull; audit lima seed menunjukkan
penyebabnya adalah MCSE yang meremehkan variasi antar-run (≈0.5×), bukan
non-determinisme. Sebaliknya, keputusan \textbf{kualitas data dan
preprocessing mendominasi hasil}: model Gaussian pada skala mentah (M0)
konvergen sempurna namun salah spesifikasi (27\% replikasi bernilai
negatif), dan RMSE validasi per-hull turun dari 8.87 (M0) menjadi 1.87
(M3). Validasi acak per baris \textbf{melebih-lebihkan} kinerja model
hierarkis sebesar 63.4 ELPD (SE 11.7) dan mengubah model yang terpilih.
Model informatif untuk prediksi (cakupan interval prediksi 95\% per-hull
M3 = 0.94; M6 sedikit konservatif, 0.99), tetapi arah efek masing-masing
rasio geometri tidak dapat dipastikan dari 22 hull.

\textbf{Kata Kunci:} Regresi Bayesian, Reproducibility, Kualitas Data,
PSIS-LOO, \emph{Data Leakage}, Yacht Hydrodynamics.

\section{BAB 1. PENDAHULUAN}\label{bab-1.-pendahuluan}

\subsection{1.1 Latar Belakang Masalah}\label{latar-belakang-masalah}

Hambatan residu per satuan berat displacement adalah komponen hambatan
kapal di luar gesekan, terutama akibat pembentukan gelombang. Nilainya
menentukan kebutuhan daya propulsi, sehingga prediksi yang akurat pada
tahap desain awal sangat bernilai. Dataset \emph{Delft Systematic Yacht
Hull Series} (UCI ID 243) memuat hasil uji \emph{towing tank} untuk 22
bentuk lambung yang diturunkan dari satu \emph{parent hull} (Standfast
43), masing-masing diuji pada 14 kecepatan (Froude number).

Regresi Bayesian menawarkan kuantifikasi ketidakpastian penuh melalui
distribusi posterior dan posterior predictive. Namun, hasil Bayesian
\textbf{bersyarat pada model, prior, data, dan komputasi}. Kesalahan
kecil pada kualitas data atau preprocessing --- misalnya skala prior
yang tidak sesuai, transformasi target, atau skema validasi yang bocor
--- dapat menghasilkan kesimpulan yang tampak meyakinkan (R̂ = 1.00,
tanpa divergensi) tetapi keliru. Karena itu, fokus project ini adalah
\textbf{reproducibility dan kualitas data}: seberapa stabil hasil
terhadap sumber variasi yang seharusnya tidak berpengaruh, dan seberapa
besar pengaruh keputusan data terhadap kesimpulan.

\subsection{1.2 Rumusan Masalah}\label{rumusan-masalah}

Pertanyaan utama: \textbf{Seberapa stabil dan informatif hasil Regresi
Bayesian pada Yacht Hydrodynamics ketika difokuskan pada reproducibility
\& data quality?} Pertanyaan ini dijabarkan menjadi empat pertanyaan
terukur:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Apakah kesimpulan berubah bila seed MCMC atau urutan baris data
  diubah? (ukuran: selisih posterior dalam satuan MCSE)
\item
  Seberapa besar dampak preprocessing (target mentah vs log, bentuk
  fungsi Froude) terhadap kecocokan dan prediksi? (ukuran: ELPD, RMSE,
  cakupan interval prediksi)
\item
  Seberapa optimis validasi acak per baris dibanding validasi per hull?
  (ukuran: selisih ELPD dan RMSE \emph{out-of-sample})
\item
  Seberapa sensitif posterior dan kesimpulan prediktif terhadap pilihan
  prior yang masih masuk akal?
\end{enumerate}

\subsection{1.3 Tujuan Penelitian}\label{tujuan-penelitian}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Mengaudit struktur dan kualitas data, termasuk ketergantungan
  observasi dalam satu hull.
\item
  Membangun baseline Regresi Bayesian yang benar dan reproducible, lalu
  memperbaikinya secara bertahap sesuai temuan diagnostik.
\item
  Mengukur stabilitas hasil terhadap seed, urutan data, prior,
  preprocessing, dan skema validasi.
\item
  Mengomunikasikan ketidakpastian estimasi dan prediksi untuk desain
  lambung baru.
\end{enumerate}

\section{BAB 2. TINJAUAN PUSTAKA}\label{bab-2.-tinjauan-pustaka}

\subsection{2.1 Hambatan Residu dan Froude
Number}\label{hambatan-residu-dan-froude-number}

Froude number \(Fr = V/\sqrt{gL}\) adalah kecepatan tak berdimensi
relatif terhadap panjang kapal. Pada \(Fr\) rendah hambatan residu
kecil. Mendekati \(Fr \approx 0.4\), kapal ``terjebak'' di antara
gelombang haluan dan buritannya sendiri sehingga hambatan meningkat
hampir eksponensial (Gerritsma dkk., 1981). Konsekuensinya bagi
pemodelan: hubungan outcome--Froude sangat non-linear, dan variasinya
membesar pada kecepatan tinggi.

\subsection{2.2 Regresi Bayesian}\label{regresi-bayesian}

Inferensi Bayesian memperbarui pengetahuan melalui teorema Bayes:

\[p(\theta\mid y) = \frac{p(y\mid\theta)\,p(\theta)}{p(y)} \propto p(y\mid\theta)\,p(\theta).\]

Untuk regresi Gaussian
\(\mathbf y\mid\beta,\sigma^2 \sim N(\mathbf X\beta, \sigma^2\mathbf I)\)
dengan prior konjugat Normal--Inverse-Gamma
\(\beta\mid\sigma^2\sim N(\mathbf m_0,\sigma^2\mathbf V_0)\) dan
\(\sigma^2\sim IG(a_0,b_0)\), posterior tersedia dalam bentuk tertutup
(Hoff, 2009):

\[\mathbf V_n=(\mathbf V_0^{-1}+\mathbf X^\top\mathbf X)^{-1},\quad \mathbf m_n=\mathbf V_n(\mathbf V_0^{-1}\mathbf m_0+\mathbf X^\top\mathbf y),\quad a_n=a_0+\tfrac n2,\quad b_n=b_0+\tfrac12\left[\mathbf y^\top\mathbf y+\mathbf m_0^\top\mathbf V_0^{-1}\mathbf m_0-\mathbf m_n^\top\mathbf V_n^{-1}\mathbf m_n\right].\]

Prediksi untuk data baru memakai posterior predictive distribution
\(p(\tilde y\mid y)=\int p(\tilde y\mid\theta)\,p(\theta\mid y)\,d\theta\),
yang menggabungkan ketidakpastian parameter dan variasi observasi. Prior
yang baik ditentukan pada skala yang bermakna dan dievaluasi dengan
\textbf{prior predictive check}: \(\theta^{(s)}\sim p(\theta)\), lalu
\(y^{(s)}\sim p(y\mid\theta^{(s)})\) (Gelman dkk., 2020).

\subsection{2.3 Komputasi dan Diagnostik
MCMC}\label{komputasi-dan-diagnostik-mcmc}

Model non-konjugat diestimasi dengan Hamiltonian Monte Carlo (NUTS)
melalui Stan/\texttt{brms} (Bürkner, 2017). Konvergensi dinilai
bersama-sama: \(\hat R\) ter-normalisasi rank ≤ 1.01, \emph{effective
sample size} (bulk \& tail) ≥ 400, tanpa \emph{divergent transitions},
serta trace/rank plot (Vehtari dkk., 2021). Galat Monte Carlo diukur
dengan \(MCSE \approx SD/\sqrt{ESS}\).

\subsection{2.4 Model Checking dan Perbandingan
Model}\label{model-checking-dan-perbandingan-model}

\emph{Posterior predictive check} (PPC) membandingkan statistik data
teramati dengan data replika \(y^{rep}\sim p(y^{rep}\mid y)\) untuk
menemukan aspek data yang gagal direproduksi model. Perbandingan
prediktif memakai \(\text{ELPD}_{LOO}=\sum_i \log p(y_i\mid y_{-i})\)
yang diaproksimasi PSIS-LOO dengan diagnostik Pareto-\(k\) (Vehtari
dkk., 2017). ELPD hanya sah dibandingkan bila semua model mendefinisikan
densitas untuk variabel yang sama. Jika target ditransformasi
\(z=g(y)\), densitas dipindahkan ke skala \(y\) dengan koreksi Jacobian:
\(\log p(y)=\log p(z)+\log|dz/dy|\).

\subsection{2.5 Reproducibility dan Kebocoran
Data}\label{reproducibility-dan-kebocoran-data}

Hasil reproducible berarti dapat direplikasi dari data mentah dan kode
tanpa langkah manual: seed, versi perangkat lunak, dan preprocessing
tercatat. Pada data berkelompok, validasi acak per baris menempatkan
observasi dari kelompok yang sama di data latih dan uji, sehingga model
``mengenal'' kelompok yang diuji (\emph{data leakage}). Estimasi kinerja
menjadi terlalu optimis bila tujuannya memprediksi kelompok baru
(Roberts dkk., 2017).

\subsection{3.5 Komputasi dan Validasi}\label{komputasi-dan-validasi}

Model di-fit dengan \texttt{brms} (Stan, NUTS): 4 chains × 1000 draws
setelah 1000 warm-up, \texttt{adapt\_delta} = 0.95, seed = 2026.
Kebenaran komputasi diverifikasi dengan membandingkan posterior analitik
konjugat, \emph{Gibbs sampler} yang ditulis manual, dan HMC di Stan pada
model dan prior yang sama.

\subsection{3.6 Audit Reproducibility dan Skema
Validasi}\label{audit-reproducibility-dan-skema-validasi}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Seed:} model final di-fit ulang dengan seed 777; bila ada
  parameter yang ditandai, dilanjutkan dengan audit lima seed (2026,
  777, 999, 31, 123) untuk membandingkan sebaran antar-run dengan MCSE
  yang dilaporkan.
\item
  \textbf{Urutan data:} seed sama, baris data diacak.
\item
  \textbf{Skema validasi:} 5-fold per hull (4--5 hull utuh ditahan tiap
  fold) dibandingkan 5-fold acak per baris. Metrik pada satuan asli:
  RMSE, MAE, cakupan dan lebar interval prediksi 95\%, serta ELPD per
  observasi.
\item
  \textbf{Sensitivitas prior:} semua SD prior M6 dikali 0.5 dan 2.5.
\end{enumerate}

Kriteria stabil: selisih mean posterior \textbar z\textbar{} \textless{}
3 dalam satuan MCSE gabungan \(z=\Delta/\sqrt{MCSE_1^2+MCSE_2^2}\).
Cross-validation memakai konfigurasi ringan (2 chains × 500 draws).

\section{BAB 5. KESIMPULAN DAN SARAN}\label{bab-5.-kesimpulan-dan-saran}

\subsection{5.1 Kesimpulan}\label{kesimpulan}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Komputasi terverifikasi dan stabil secara substantif.}
  Posterior MCMC cocok dengan solusi analitik dan Gibbs (≤ 1.02 MCSE).
  Kesimpulan prediktif tidak berubah antar lima seed maupun urutan data,
  dan prior yang masih masuk akal tidak mengubah kesimpulan. Namun MCSE
  dari satu run meremehkan variabilitas antar-run untuk SD efek hull
  (≈0.5×), sehingga audit reproducibility perlu memakai beberapa seed.
\item
  \textbf{Keputusan kualitas data dan preprocessing mendominasi hasil.}
  Baseline Gaussian pada skala mentah konvergen sempurna tetapi salah
  spesifikasi. Transformasi log dan bentuk fungsi Froude yang fleksibel
  memperbaiki ELPD dan RMSE secara drastis. Prior yang salah skala
  mengubah kesimpulan tanpa peringatan konvergensi, sehingga prior
  predictive check wajib dilakukan.
\item
  \textbf{Skema validasi adalah sumber optimisme terbesar} dan bahkan
  mengubah model yang terpilih. Untuk estimand utama (prediksi lambung
  baru), validasi harus dilakukan per hull.
\item
  \textbf{Informatif untuk prediksi, terbatas untuk inferensi geometri.}
  Kurva resistance--Froude, heteroskedastisitas, dan variasi antar-hull
  diestimasi dengan presisi tinggi. Interval prediksi 95\% M3
  terkalibrasi baik untuk hull baru (cakupan 0.94), sedangkan M6 sedikit
  konservatif (0.99). Namun arah efek tiap rasio geometri tidak dapat
  dipastikan (22 hull, VIF tinggi).
\end{enumerate}

\subsection{5.2 Keterbatasan}\label{keterbatasan}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Hanya 22 hull yang semuanya turunan satu \emph{parent hull};
  generalisasi ke keluarga desain lain tidak didukung.
\item
  Geometri divariasikan satu per satu di sekitar \emph{parent hull},
  sehingga efeknya lokal dan interaksi geometri tidak teridentifikasi.
\item
  Froude hanya 14 level (0.125--0.45); prediksi di luar rentang ini
  adalah ekstrapolasi.
\item
  Transformasi \(\log(1+y)\) masih mengizinkan nilai −1 \textless{} y
  \textless{} 0.
\item
  Galat pengukuran \emph{towing tank} tidak terdokumentasi.
\item
  Efek geometri adalah asosiasi dalam desain eksperimen ini, bukan klaim
  kausal umum.
\end{enumerate}

\subsection{5.3 Saran dan Pengembangan}\label{saran-dan-pengembangan}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Gunakan validasi per hull (atau per kelompok) untuk setiap klaim
  prediktif pada data berkelompok, dan laporkan optimisme skema acak
  sebagai bagian audit.
\item
  Uji likelihood yang hanya berlaku pada \(y>0\) (lognormal atau Gamma)
  untuk menghilangkan sisa pelanggaran support.
\item
  Untuk prediksi desain baru, gunakan model berbasis spline Froude yang
  lebih sederhana; gunakan M6 untuk menjelaskan struktur data.
\item
  Tambahkan data dari keluarga lambung lain agar efek geometri dapat
  diidentifikasi.
\end{enumerate}

make_frames <- function(train, test = NULL) {
  sc <- lapply(PRED, function(v) c(mean(train[[v]]), sdp(train[[v]])))
  names(sc) <- PRED
  sc$y  <- c(mean(train$Resistance), sdp(train$Resistance))
  ly    <- log1p(train$Resistance)
  sc$ly <- c(mean(ly), sdp(ly))
  basis <- bs((train$Froude_No - sc$Froude_No[1]) / sc$Froude_No[2], df = 6)  # B-spline kubik, knot dari train
  tf <- function(d) {
    o <- as.data.frame(lapply(setNames(PRED, paste0("z_", PRED)),
                              function(v) (d[[v]] - sc[[v]][1]) / sc[[v]][2]))
    o$zF2 <- o$z_Froude_No^2
    o$zF3 <- o$z_Froude_No^3
    B <- predict(basis, o$z_Froude_No)
    colnames(B) <- paste0("F", 1:6)
    o <- cbind(o, as.data.frame(B))
    o$y_z  <- (d$Resistance - sc$y[1]) / sc$y[2]
    o$ly_z <- (log1p(d$Resistance) - sc$ly[1]) / sc$ly[2]
    o$hull <- sprintf("H%02d", d$hull_id)
    o$hull_id <- d$hull_id
    o$Froude_No <- d$Froude_No
    o$Resistance <- d$Resistance
    o
  }
  list(train = tf(train), test = if (!is.null(test)) tf(test), sc = sc, tf = tf)
}

# s = pengali skala SD prior (1 = dasar, 0.5 lebih ketat, 2.5 lebih lebar) untuk analisis sensitivitas
make_prior <- function(sp, s = 1) {
  p <- prior_string(sprintf("normal(0, %g)", 1 * s), class = "Intercept") +
       prior_string(sprintf("normal(0, %g)", 0.5 * s), class = "b")                  # geometri
  for (v in sp$froude) p <- p + prior_string(sprintf("normal(0, %g)", 1 * s), class = "b", coef = v)
  if (sp$spline) for (k in 1:6) p <- p + prior_string(sprintf("normal(0, %g)", 1.5 * s), class = "b", coef = paste0("F", k))
  if (sp$hetero) {
    p <- p + prior_string(sprintf("normal(-1.5, %g)", 0.75 * s), class = "Intercept", dpar = "sigma") +
             prior_string(sprintf("normal(0, %g)", 0.5 * s), class = "b", dpar = "sigma")
  } else {
    p <- p + prior_string(sprintf("exponential(%g)", 1 / s), class = "sigma")          # rate = 1/s
  }
  if (sp$fam == "student") p <- p + prior(gamma(2, 0.1), class = "nu")               # shape-rate
  if (sp$hier) p <- p + prior_string(sprintf("normal(0, %g)", 0.25 * s), class = "sd")  # half-normal
  p
}

# Kompatibilitas cache loo:
# Object loo yang tersimpan dari versi package lama dapat memiliki struktur

# dan bila cache lama tidak menyimpannya, hitung ulang LOOS dari fit saat ini.
extract_pareto_k <- function(x) {
  if (is.null(x)) return(NULL)

  # Struktur utama pada loo modern
  if (!is.null(x$diagnostics) && !is.null(x$diagnostics$pareto_k)) {
    return(as.numeric(x$diagnostics$pareto_k))
  }

  # Fallback yang tetap tersedia pada objek loo dengan pointwise diagnostics
  if (!is.null(x$pointwise) &&
      "influence_pareto_k" %in% colnames(x$pointwise)) {
    return(as.numeric(x$pointwise[, "influence_pareto_k"]))
  }

  # Fallback terakhir bila psis object tersimpan
  if (!is.null(x$psis_object)) {
    out <- tryCatch(loo::pareto_k_values(x$psis_object),
                    error = function(e) NULL)
    if (!is.null(out)) return(as.numeric(out))
  }

  NULL
}

hdi <- function(v, prob = .95) {
  v <- sort(v); k <- floor(prob * length(v)); w <- v[(k + 1):length(v)] - v[1:(length(v) - k)]
  i <- which.min(w); c(v[i], v[i + k])
}

logmeanexp <- function(x) { m <- max(x); m + log(mean(exp(x - m))) }
make_folds <- function(scheme) {
  if (scheme == "grouped") {
    hulls <- sort(unique(full$hull_id))
    fold_of_hull <- rep(1:5, length.out = length(hulls))            # 22 hull -> fold berisi 4-5 hull utuh
    fold_of_hull[match(full$hull_id, hulls)]
  } else {
    set.seed(SEED); sample(rep(1:5, length.out = nrow(full)))
  }
}
cv_eval <- function(name, scheme) cache_rds(paste0("cv_", name, "_", scheme), {
  sp <- SPECS[[name]]
  resp <- if (sp$resp == "raw") "y_z" else "ly_z"
  folds <- make_folds(scheme)
  recs <- list(); rhats <- c()
  for (k in 1:5) {
    fr <- make_frames(full[folds != k, ], full[folds == k, ])
    f <- update(FITS[[name]], newdata = fr$train, chains = CV_SAMPLER$chains, iter = CV_SAMPLER$iter,
                warmup = CV_SAMPLER$warmup, seed = SEED + k, refresh = 0, silent = 2, recompile = FALSE)
    rhats <- c(rhats, max(summarise_draws(as_draws_array(f, variable = MAIN_PAR(f)), "rhat")$rhat))
    ll <- log_lik(f, newdata = fr$test, allow_new_levels = TRUE, sample_new_levels = "gaussian")
    lpd <- apply(ll, 2, logmeanexp) + jacobian(fr$test, sp$resp, fr$sc)
    set.seed(SEED + k)
    yr <- to_raw(posterior_predict(f, newdata = fr$test, allow_new_levels = TRUE, sample_new_levels = "gaussian"),
                 sp$resp, fr$sc)
    recs[[k]] <- data.frame(fold = k, hull_id = fr$test$hull_id, Froude_No = fr$test$Froude_No,
                            y = fr$test$Resistance, pred_mean = colMeans(yr),
                            lo = apply(yr, 2, quantile, .025), hi = apply(yr, 2, quantile, .975), lpd = lpd)
  }
  r <- bind_rows(recs)
  list(pred = r, summary = data.frame(
    model = name, scheme = scheme, RMSE = sqrt(mean((r$y - r$pred_mean)^2)), MAE = mean(abs(r$y - r$pred_mean)),
    coverage_95 = mean(r$y >= r$lo & r$y <= r$hi), PI_width = mean(r$hi - r$lo),
    ELPD_per_obs = mean(r$lpd), ELPD_total = sum(r$lpd), max_rhat_folds = max(rhats)))
})

safe_csv <- function(x, file) {
  x <- as.data.frame(x, stringsAsFactors = FALSE)

  for (j in seq_along(x)) {
    if (is.factor(x[[j]])) {
      x[[j]] <- as.character(x[[j]])
    } else if (is.list(x[[j]])) {
      x[[j]] <- vapply(
        x[[j]],
        function(v) {
          if (length(v) == 0L || all(is.na(v))) return("")
          paste(as.character(unlist(v, use.names = FALSE)), collapse = "; ")
        },
        character(1)
      )
    }
  }

  utils::write.csv(x, file, row.names = FALSE, na = "")
}
